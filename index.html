⚡ 1. Что такое Python?

Python — это высокоуровневый интерпретируемый язык программирования с динамической типизацией. Он идеально подходит для веб-разработки, асинхронных Telegram-ботов, ИИ и скриптов автоматизации.

📦 2. Переменные и Типы данных

В Python переменная создается автоматически при присвоении ей значения. Тип данных определяется динамически на этапе выполнения.

# Основные типы данных в Python name = "MexoMC" # str (строка) age = 15 # int (целое число) is_dev = True # bool (логический тип) print(f"Разработчик: {name}, Возраст: {age}")

⚙️ 3. Как работает интерпретатор?

В отличие от компилируемых языков (C++, Rust), исходный код Python (.py) сначала переводится в байт-код (.pyc), а затем исполняется виртуальной машиной Python (PVM — Python Virtual Machine).

Исходный код (.py) ➔ Байт-код (.pyc) ➔ PVM (Виртуальная машина) ➔ Выполнение
