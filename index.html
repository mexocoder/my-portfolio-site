⚡ 1. Что вообще за Python?

Python - это скриптовый язык с динамической типизацией. На нем удобно пишется всё: от простых скриптов автоматизации до асинхронных ТГ-ботов на aiogram и работы с нейросетями.

📦 2. Переменные и типы данных

В питоне не нужно вручную объявлять типы как в C++. Язык сам понимает, что за значение лежит в переменной прямо во время выполнения кода.

# объявляем переменные name = "MexoMC" # обычная строка age = 15 # число (int) is_dev = True # булево значение # вывод через f-строку (самый удобный способ) print(f"Автор: {name}, возраст: {age}")

⚙️ 3. Как это работает под капотом?

Питон не компилирует код напрямую в машинные нули и единицы. Сначала файл .py переводится в байт-код (.pyc), а уже потом виртуальная машина PVM читает его и выполняет.

Код (.py) -> Байт-код (.pyc) -> PVM (Python Virtual Machine) -> Результат
